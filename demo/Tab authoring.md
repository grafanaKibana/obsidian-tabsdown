# Add and rename tabs

Right-click this block and choose **Add tab**. Enter a label, then press Enter to save a new tab with an empty body. Escape or clicking outside cancels without changing the note.

Double-click **Overview** to rename it. **Rename tab** is also available from a tab's context menu. The editor keeps Markdown formatting visible and preserves the icon prefix without showing it.

```tabsdown
config: personality=button, alignment=equal-width

tab: icon:book-open Overview

Start here. Tab switching never changes the Markdown.

tab: icon:pencil **Try it**

Rename this label, or add another tab from the context menu.

tab: Delete me

This tab and its content can be deleted from its context menu after confirmation.
```

With Style Settings installed, open **Tabsdown → Tab appearance → Corner radius**. **Auto** follows the theme; **Custom** uses the corner-radius slider for Button tabs and the Rail track and tabs. Underline and Separator stay square.
